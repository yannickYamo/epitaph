## Review before the gate (G1.5)

An independent review of the whole phase 1 diff found eleven issues. Fixed, each with a
regression test:

- the watchdog now reflects progress of the life loop: a state that overruns its budget first
  kills the creature (cause `hang`), and only a loop that still does not move stops the pings,
  so systemd restarts it;
- the supervisor survives an exception in any pass; an unexpected exit fails the controller
  loudly;
- a failed transcript or bus write (a full or failing SD card) no longer takes the controller
  down;
- bounded memory (the ping history), bounded waits (llama-server stop, slot save and restore);
- blocking body calls (the sudo clock helper, cgroup waits) run off the event loop;
- a bad `ctl new-life` request is refused before the current life is touched; a life whose
  setup fails is closed as a crash and the next one is born;
- a life cut off during its load is recovered as `interrupted`;
- the boot check fails loudly when the Pi does not answer; the unused notifier is gone and
  `STOPPING=1` is sent on shutdown.

One finding is accepted rather than fixed: the service runs as `pi`, whose blanket sudo makes the
narrow clock rule moot (ADR-027).

The first real life also showed a transcript bug: the death line came before the last reading.
Fixed with the rest.
