## Review before the gate (G2.4)

Ten findings on the phase 2 diff, all fixed with tests. The two that mattered most: the network
rule was checked only when the controller started (a restart of nftables would have reopened
the creature's network until the next restart), and the root helper relied on sudo alone to
refuse a multi-line argument. Both now fail closed.
